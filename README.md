# isy-ueberwachung

Diese Bibliothek ermöglicht eine einfache Überwachung einer Anwendung für den Betrieb.

## IsyFact

## Features

- **Health-Überwachung**: Integration von Spring Boot Actuator Health-Endpunkten mit Unterstützung für Nachbarsystem-Checks
- **Service-Statistiken**: Metriken für Service-Aufrufe (Anzahl, Durchschnittsdauer, Fehler)
- **Loadbalancer-Steuerung**: Servlet-basierte Kontrolle des Loadbalancings via IsAlive-Datei
- **Actuator-Sicherheit**: Konfigurierbare Sicherheitseinstellungen für Actuator-Endpunkte
- **Auto-Konfiguration**: Spring Boot Auto-Configuration für alle Komponenten
